# Son Makaleler

Ayarlar'dan GitHub bilgilerini girdikten sonra makaleler burada görünür.

# Hızlı Başlangıç
  1. Ayarlar sekmesine git → GitHub Token, repo sahibi ve repo adını gir
  2. Yeni Makale sekmesine git → formu doldur, içeriğini yapıştır
  3. Yayınla butonuna bas → makale otomatik GitHub'a gönderilir
  4. GitHub Pages 1-2 dk içinde siteyi günceller

GitHub bağlantısı ve şifre yönetimi

GitHub Personal Access Token nasıl alınır?
GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → Scope: repo işaretle → Token'ı kopyala.

Önemli: Token'ı sessionStorage'da tutuyoruz. Tarayıcı kapanınca silinir — her oturum açışında tekrar girilmesi gerekir (güvenli).
